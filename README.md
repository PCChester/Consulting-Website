# Chris Chester — Communication, Leadership and AI Adoption Training

Website for Chris Chester's training practice, based in Valencia, Spain: communication,
leadership and AI adoption courses for teams whose work is technical, delivered in-house
or online.

**Live site:** [chrischesterconsulting.com](https://chrischesterconsulting.com/)

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Hero, the problem, the four course families, how a course comes together |
| `courses.html` | Course catalogue in four families: Communication, Leadership and executive, AI adoption, Data storytelling |
| `about.html` | Background: thirty years of training and communication across borders |
| `recent-work.html` | Training delivered, plus a short list of technical projects |
| `faq.html` | Common questions |
| `contact.html` | Email and LinkedIn |
| `blog.html` | Articles |
| `privacy.html` | Privacy and terms |
| `es/` | Spanish pages (being rewritten) |

`/projects.html` redirects to `/recent-work.html` (see `netlify.toml`).

## Design

- Fonts: Lora (headlines), DM Sans (body), DM Mono (labels)
- Palette: warm paper, terracotta `#c05c2b`, teal `#2a7a6a`, gold `#b87c2a`
- Plain HTML, CSS and vanilla JavaScript. No framework, no build step.

## Hosting

- Netlify, auto-deploys from `main`
- Comments on blog articles via Giscus (GitHub Discussions)
- Analytics: Google Analytics 4

## Running locally

```bash
git clone https://github.com/PCChester/Portfolio-Website.git
cd Portfolio-Website
# open index.html in a browser
```

Giscus comments only load on the live site.
